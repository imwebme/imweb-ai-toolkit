§ 04 · 설치

평소 쓰는 AI 에이전트에 — 이 한 줄.

외울 명령어, 환경별 다른 설명서 — 없습니다. 가장 쉬운 건 AI 에이전트에게 직접 부탁하는 것.

가장 쉬운 방법
Claude · Codex · Claude Desktop — 이미 쓰는 AI 대화창에 그대로 붙여넣으세요.
github.com/imwebme/imweb-ai-toolkit 보고 설치해줘

에이전트가 환경을 알아서 감지하고, 공식 imweb CLI 설치까지 같이 처리합니다. 설치 후엔 — "최근 주문 중 이상한 거 있어?" 같은 한 문장만 보내면 끝.

또는 환경별로 직접 설치하기

Claude Code 채팅창에 — 아래 두 줄을 순서대로 실행하면 끝.

/plugin marketplace add imwebme/imweb-ai-toolkit /plugin install imweb-ai-toolkit@imweb-ai-toolkit

설치되는 것 — imweb 스킬 + 로컬 CLI 브리지. 첫 사용 시 imweb 로그인을 브라우저에서 한번 마치면 됩니다.

Codex CLI 또는 앱에서 — 마켓플레이스에 등록한 뒤 Plugins UI에서 추가하세요.

codex plugin marketplace add imwebme/imweb-ai-toolkit --ref main

등록 후 Plugins UI에서 imweb-ai-toolkit 을 활성화하면 Codex 세션에서 바로 사용할 수 있습니다.

Claude Desktop을 쓰신다면 — 원클릭 MCPB 번들을 만들어 설치합니다.

npx -y github:imwebme/imweb-ai-toolkit --tool claude-desktop

생성된 imweb-ai-toolkit.mcpb 를 Claude Desktop으로 열고 Install — 번들 안의 MCP 브리지가 첫 사용 시 CLI 설치/업데이트를 관리합니다.

Claude Desktop Cowork task 안에서 — Claude에게 이 한 마디를 보내세요.

아임웹 도구 패키지를 설치해줘: npx -y github:imwebme/imweb-ai-toolkit --tool claude-cowork imweb-ai-toolkit.plugin과 imweb.skill을 저장할 수 있게 보여줘.

plugin · skill 카드를 수락한 다음 — "아임웹툴로 최근 주문 중 이상 거래를 조사해줘" 처럼 자연어로 일을 시키면 됩니다.

에이전트 없이 — imweb CLI만 깔고 싶으시다면.

npx -y github:imwebme/imweb-ai-toolkit --tool cli

Codex와 Claude Code에 동시 설치하실 거면 — --tool both 로 한 번에 끝낼 수도 있습니다.

정리하고 싶으시면 — Codex와 Claude Code 설정을 한 번에 제거합니다.

npx -y github:imwebme/imweb-ai-toolkit --uninstall --tool both

생성된 .plugin / .skill / .mcpb 아티팩트와 CLI까지 모두 정리하려면 — --tool all 로 끝까지 청소할 수 있습니다. imweb 로그인 데이터는 그대로 유지돼요.

§ 06 · 신뢰와 경계

이 툴킷이 하는 일과 하지 않는 일.

이것은 호스팅 서비스가 아닙니다. 코드는 공개되어 있고, 내 컴퓨터에서만 동작합니다.

+

이런 일은 합니다

  • AI 에이전트를 공식 imweb CLI 에 연결합니다.
  • CLI를 로컬에서 설치 / 업데이트합니다.
  • 기존 imweb 인증 을 재사용하며, 필요할 때 브라우저 로그인을 요청합니다.
  • 플러그인 메타데이터, 스킬 자산, 설치 스크립트, 문서, 예시를 제공합니다.
  • Claude Desktop 흐름을 위한 로컬 MCP 브리지 를 제공합니다.
−

이런 일은 안 합니다

  • 데이터를 호스팅하거나 클라우드 서비스로 중계하지 않습니다.
  • 쇼핑몰에 자동으로 변경 작업 을 실행하지 않습니다 (읽기 전용).
  • CLI가 제공하지 않는 트래픽 순위나 비공개 지표를 약속하지 않습니다.
  • 공식 imweb CLI를 대체하지 않습니다 — 옆에서 함께 동작합니다.
  • 이 사이트에서 텔레메트리나 추적 스크립트를 보내지 않습니다.
